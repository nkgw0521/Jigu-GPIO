# 作業環境

- このリポジトリはネットワークドライブ `X:\Tools` にある。
- ネットワークドライブであることは既知の正常な構成として扱う。
- ドライブ構成の調査、速度測定、ローカルコピーの提案は行わない。
- 大規模な再帰走査を避け、`rg` と `rg --files` で対象を絞る。
- `.git`、`node_modules`、`target`、ビルド生成物を不要に走査しない。
- `X:` がシェルから見えない場合、何度も再試行したりドライブ割り当てを調査したりしない。
- パスへアクセスできない場合は、環境またはサンドボックス上の問題として簡潔に報告する。
- ローカルへのコピーや別ワークツリーの作成は、ユーザーから明示的な依頼がある場合だけ行う。
- 必要なファイルだけを読み、依頼された作業を直接進める。
